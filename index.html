PIMPIM

Your VALORANT community companion. Competitive ranks, player statistics, community leaderboards and more.

● IN DEVELOPMENT

01 / Features

Rank Tracking

Track VALORANT competitive ranks through Discord.

Player Statistics

Access player information and match statistics using authorized Riot Games API endpoints.

Leaderboards

Planned community rankings for participating players.

02 / Community Tournaments

Future development may include VALORANT tournaments organized for the MAJT3ERCORE Discord community. Planned features include participant registration, tournament standings and match results. These features are not yet available.

03 / Privacy & Data

PimPim is an independent Discord bot currently under development for the MAJT3ERCORE community.

Riot accounts will only be linked voluntarily. Authorized Riot Games API data will be used to provide player statistics, competitive information and community features.

PimPim does not request Riot account passwords and does not modify gameplay.

For privacy inquiries or data removal requests, please contact the project administrator through the MAJT3ERCORE community.
